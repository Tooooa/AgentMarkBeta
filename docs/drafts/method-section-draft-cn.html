3. Problem Formulation

写作策略：Section 3 的 notation 和 channel model 直接沿用 ACL，只补充新增的 rank-consistency 假设和扩展的 threat model。

We adopt the planning-time behavior channel formulation of Huang et al. (2026). At each step t, the agent induces a distribution Pt over a finite behavior set Bt and selects b̂t ← Enc(Pt, rt), where rt is keyed pseudorandomness derived from a shared secret Ksh and step context. The verifier recovers the payload via m̂ ← Dec({(b̂t, ·)}t∈I), where I ⊆ {1, …, T} is the observed index set.

We retain the distribution-preservation requirement (Eq. 1 of Huang et al., 2026):

Pr[b̂t = b] = Pt(b),   ∀ b ∈ Bt, ∀ t.

3.1 Extended Threat Model

AgentMark-F (Huang et al., 2026) assumes the verifier has access to the exact per-step distribution Pt used during encoding. In practice, this assumption is fragile: the verifier may re-query the agent to reconstruct Pt, but temperature scaling, quantization, model updates, or API-side post-processing can shift the returned probability values. We formalize this as a distribution-perturbation adversary:

Definition 1 (Distribution perturbation). The adversary applies a per-step transformation Pt ↦ Pt' such that probability values change but the rank ordering is preserved: argsort(Pt) = argsort(Pt').

This is strictly stronger than the erasure/truncation adversary of Huang et al. (2026): step erasure removes entire steps, while distribution perturbation corrupts the content of surviving steps. AgentMark-F's differential recombination relies on exact probability values for bin construction; under distribution perturbation, the encoder and decoder construct different bins, breaking synchronization and causing decoding failure (we verify this empirically in Section 5).

3.2 Rank-Consistency Assumption

We introduce the following relaxation of the exact-distribution requirement:

Assumption 1 (Rank consistency). The decoder observes a distribution Pt' such that argsort(Pt') = argsort(Pt), i.e., the relative ordering of behaviors is preserved.

This assumption is empirically well-supported: rank ordering is stable under temperature scaling (pi' = pi1/T / Z is monotonic), minor fine-tuning, and quantization, all of which predominantly scale magnitudes while preserving relative order (we validate this in Section 5, Table X).

Goal. Design an encoder Enc and decoder Dec such that: (1) distribution preservation holds as before, (2) the decoder requires only argsort(Pt')—not the exact values—enabling correct decoding under Assumption 1.

4. AsymAgentMark: Asymmetric Behavioral Watermarking

We propose AsymAgentMark, an asymmetric extension of the AgentMark paradigm. While both AsymAgentMark and AgentMark-F share the distribution-preservation goal, AsymAgentMark redesigns both the encoder and decoder: the encoder replaces differential recombination with a binary partition tree over rank-sorted behaviors, and the decoder exploits the tree's structural property to extract bits from rank positions alone, without probability values. This co-design is essential—AgentMark-F's differential recombination encodes bits into probability-dependent bins that cannot be recovered from rank information alone, so asymmetric decoding requires a fundamentally different encoding scheme.

We present a concrete instantiation, AsymAgentMark-T, which operates on the top-k ranked behaviors via recursive binary splitting. The "-T" denotes top-k rank-based encoding: the encoder restricts attention to the k highest-probability behaviors, embeds bits within this subset, and falls back to standard sampling for tail behaviors. This top-k focus both concentrates embedding capacity on the most informative actions and aligns naturally with common inference-time truncation strategies.

Core insight. The binary partition tree maps each behavior to a unique leaf via interleaved splitting. The path from root to leaf is fully determined by the behavior's rank in the sorted ordering—the rank expressed in binary is the path. This structural correspondence is what enables asymmetric decoding: the encoder uses probability values to make distribution-preserving group selections (via BinEnc), while the decoder reads the same path back from the rank alone.

4.1 Overview

[Figure 2 规划]：与 ACL Figure 2 对称的布局。左侧 Agent Workflow 保持一致（沿用 ACL 的 agent loop 示意）。右侧 AsymAgentMark-T 替换原有的 DiffRecombine + CyclicShift 模块，改为：Sort by rank → Top-k selection → Binary Partition Tree → BinEnc per level。底部新增一个对比框："Decoder requires: AgentMark-F needs Pt (exact) vs. AsymAgentMark-T needs σt (rank only)"，用颜色区分。

Figure 2 illustrates AsymAgentMark-T within the agent workflow. At each round t:

  1. The agent elicits an explicit behavior distribution Pt over Bt (identical to AgentMark-F).
  2. The encoder sorts Bt by descending probability, selects the top-k behaviors, and embeds bits via recursive binary splitting over this subset (RankEnc). If the sampled action falls outside the top-k, no bits are embedded for that step.
  3. The decoder, given only the selected behavior b̂t and the rank ordering σt, extracts bits by decomposing the rank of b̂t within the top-k set into binary (RankDec).

The keyed pseudorandomness mechanism is identical to AgentMark-F (Eq. 9 of Huang et al., 2026): Kt ← H(Ksh ∥ t ∥ ht), and a DRBG G seeded by Kt produces the per-step random stream. We adopt the Meteor-style HMAC-SHA512 DRBG [Kaptchuk et al., 2021] (construction details in Appendix A).

4.2 Rank-Based Distribution-Preserving Encoding

AsymAgentMark-T replaces AgentMark-F's differential recombination with a binary partition tree over the top-k rank-sorted distribution. The construction has two levels: a binary encoding primitive (BinEnc) and a recursive wrapper (RankEnc).

Binary Encoding Primitive

At each tree level, the encoder faces a binary choice between two groups of behaviors. BinEnc attempts to embed one message bit into this choice while exactly preserving the marginal distribution. It succeeds (embedding 1 bit) when the low-mass group is selected, and defers (embedding 0 bits) when the high-mass group is selected—in which case the same message bit is retried at the next level.

Given group masses Shi ≥ Slo (with S = Shi + Slo), a message bit m, and pseudorandom r ← G:

rm = (r · S + ½ S · m) mod S

The encoder selects the high-mass group if rm < Shi (embedding 0 bits), or the low-mass group otherwise (embedding 1 bit). Distribution preservation follows from the uniform distribution of r (proof in Appendix B).

Recursive Encoding with Top-k Selection

[Figure 3 规划]：5-action 示例，与 ACL 的 differential recombination 示例并排对比。左列标 "AgentMark-F: DiffRecombine → Bins → CyclicShift"，右列标 "AsymAgentMark-T: Top-k → Sort → Binary Partition Tree"。底部 highlight：同一个 action 被选中后，AgentMark-F 解码需要精确概率重建 bin，AsymAgentMark-T 解码只需 rank 位置。

Algorithm 1: AsymAgentMark-T Encode (one step)

Require: P_t over B_t, context (t, h_t), shared secret K_sh,
         payload M, pointer ℓ, top-k parameter k
Ensure:  selected behavior b̂_t, embedded bits s_t, updated ℓ

1:  K_t ← H(K_sh ∥ t ∥ h_t);  G ← DRBG(K_t)
2:  σ ← argsort(P_t, descending)
3:  S_top ← Σ_{i=1}^{k} P_t(σ(i))                ▷ top-k probability mass
4:  if Uniform(0,1) ≥ S_top:                       ▷ falls into tail (independent of G)
5:      b̂_t ← sample from tail {σ(k+1), ...}; return b̂_t, ∅, ℓ
6:  D ← {(σ(i), P_t(σ(i))/S_top) : i = 1..k}     ▷ top-k normalized dist
7:  sync ← ⌈log₂ k⌉
8:  while |D| > 1 and ℓ < |M|:
9:      D_even ← {D[i] : i even};  D_odd ← {D[i] : i odd}
10:     (group, b) ← BinEnc(M[ℓ], (Σ D_even, Σ D_odd), G.next())
11:     ℓ ← ℓ + b;  sync ← sync − 1;  D ← D_group
12: for i = 1 to sync: G.next()                    ▷ PRG synchronization
13: b̂_t ← D[0];  s_t ← M[ℓ_old : ℓ]
14: return b̂_t, s_t, ℓ

Top-k selection (lines 3–6). Rather than encoding over the full behavior set, AsymAgentMark-T restricts to the k highest-probability behaviors. This design is motivated by three considerations: (1) rank stability—the top-k ranks are the most robust to probability perturbation, since the probability gap between top-ranked behaviors is typically larger than among tail behaviors; (2) inference alignment—many agent deployments already apply top-k truncation, making this a natural fit; (3) embedding concentration—the top-k behaviors carry the majority of probability mass, so restricting to them sacrifices little capacity while improving robustness. When k = |Bt|, AsymAgentMark-T reduces to full-distribution encoding.

Interleaved partition. At each level, we partition the sorted distribution into even-indexed and odd-indexed elements. Since the distribution is sorted descending, the even-indexed group (containing ranks 0, 2, 4, ...) always has total mass ≥ the odd-indexed group (ranks 1, 3, 5, ...). This interleaving ensures approximately balanced group masses, maximizing the per-level embedding opportunity. A naive top-half/bottom-half split would create a dominant high-mass group, causing BinEnc to almost always select it with near-zero embedding rate.

PRG synchronization (rt_sync). The DRBG advances by exactly ⌈log₂ k⌉ calls per step regardless of early termination (line 12). This fixed-budget invariant is critical: without it, the decoder cannot determine how many DRBG values were consumed, causing stream desynchronization for all subsequent steps. This mechanism also enables the decoder to operate without knowing the message length—a property not available in AgentMark-F's variable-length cyclic shift encoding.

4.3 Weakly Asymmetric Decoding

The central contribution of AsymAgentMark is a co-designed encoder–decoder pair where the encoder's binary partition tree structure directly enables a decoder that requires strictly less information. The encoder's tree design is not incidental—it is the structural prerequisite that makes asymmetric decoding possible.

Key observation. The binary partition tree maps each behavior to a unique leaf. The path from root to a behavior's leaf is fully determined by the behavior's rank within the top-k set: at each level, membership in the high-mass or low-mass group corresponds to whether the current index is even or odd—i.e., the parity of the rank at that level. Therefore, the rank in binary is the encoding path. This property is unique to the interleaved binary partition; AgentMark-F's differential bins do not admit such rank-based path recovery.

Algorithm 2: AsymAgentMark-T Decode (one step)

Require: b̂_t, rank ordering σ_t, context (t, h_t), shared secret K_sh,
         top-k parameter k
Ensure:  extracted bitstring s_t

1:  K_t ← H(K_sh ∥ t ∥ h_t);  G ← DRBG(K_t)
2:  rank ← position of b̂_t in σ_t[1..k] (0-indexed)
3:  if b̂_t ∉ top-k of σ_t: return ∅           ▷ tail action, no bits
4:  sync ← ⌈log₂ k⌉
5:  R ← [G.next() for _ in range(sync)]
6:  s_t ← "";  level ← 0
7:  while rank ≠ 0:
8:      if rank mod 2 = 1:                      ▷ odd-indexed group → bit embedded
9:          s_t ← s_t ∥ ('1' if R[level] < 0.5 else '0')
10:     rank ← ⌊rank / 2⌋;  level ← level + 1
11: return s_t

Note the asymmetry: Algorithm 1 (encoder) accesses the full distribution Pt to compute group masses for BinEnc (line 10). Algorithm 2 (decoder) accesses only the rank ordering σt (line 2)—probability values never appear. The decoder only needs to know which position (rank) the selected behavior occupies within the top-k set.

Theorem 1 (Weak asymmetry). Let Pt and Pt' be distributions over Bt with argsortk(Pt) = argsortk(Pt') (i.e., the top-k rank ordering is preserved). For any behavior b̂t and DRBG state G:

Decode(b̂t, sort(Pt), G) = Decode(b̂t, sort(Pt'), G)

Proof. Decode accesses Pt solely through the top-k ordering σt = argsortk(Pt). Since this ordering is preserved, the rank of b̂t within the top-k set is identical under both distributions. The DRBG sequence depends only on (Ksh, t, ht), not on probability values. □

4.4 Comparison with AgentMark-F

Both AgentMark-F and AsymAgentMark-T are distribution-preserving instantiations of the AgentMark paradigm. They differ in the decomposition strategy, the decoder information requirement, and the resulting robustness profile:

AgentMark-F (Huang et al., 2026)AsymAgentMark-T (Ours)
DecompositionDifferential recombination → uniform binsTop-k rank-sorted binary partition tree
Encoder inputPt (exact probabilities)Pt (exact probabilities)
Decoder inputPt (exact probabilities)σt (top-k rank ordering only)
Bits/stepVariable, depends on bin sizes≤ ⌈log₂ k⌉
PRG syncFixed 2 calls/step (implicit)Explicit fixed budget ⌈log₂ k⌉
RobustnessErasure/truncation (via RLNC)Erasure + distribution perturbation
VulnerabilityProbability perturbation breaks bin syncRank-swap attacks (within top-k) break rank sync

When to prefer which. AgentMark-F achieves higher embedding rates in controlled environments where exact Pt is available at decode time (e.g., the embedder and verifier share the same API and configuration). AsymAgentMark-T is preferred when the verifier cannot guarantee exact Pt—the common case in open-world deployments where agents are re-served, fine-tuned, or accessed through different API configurations. The top-k restriction further improves robustness by focusing on the most rank-stable behaviors.

Compatibility with RLNC. AsymAgentMark-T is fully compatible with the RLNC erasure coding layer of AgentMark-F. The per-step embedded bits st from Encode can serve as RLNC coded packets in the same way as AgentMark-F's cyclic-shift output (Section 4.3 of Huang et al., 2026).

4.5 Security Properties

AsymAgentMark-T achieves the same security guarantees as AgentMark-F, through a different construction:

Distribution preservation. BinEnc with uniform message bits produces a marginal that exactly matches Pt over the top-k set (Proposition 1; proof in Appendix B). Combined with the probability-proportional tail fallback (Algorithm 1, line 4–5), the overall marginal matches Pt across all behaviors. Both AsymAgentMark-T and AgentMark-F satisfy the same distribution-preservation property (Eq. 1), but through entirely different mechanisms: AgentMark-F via differential recombination over probability-dependent uniform bins, AsymAgentMark-T via recursive BinEnc over a rank-sorted binary partition tree.

Undetectability. Under the PRF assumption on HMAC-SHA512, the DRBG output is computationally indistinguishable from uniform random bits, making the watermarked behavior sequence indistinguishable from unwatermarked sampling. This follows directly from the Meteor DRBG security argument [Kaptchuk et al., 2021] and the FDPSS framework [Liao et al., 2025].

New: Perturbation robustness. By Theorem 1, AsymAgentMark-T additionally guarantees correct decoding under any distribution perturbation that preserves the top-k rank ordering—a property that AgentMark-F does not possess. The top-k restriction strengthens this guarantee: the probability gaps among the most dominant behaviors are typically larger, making their ranks more resistant to perturbation. We quantify this boundary (i.e., the minimum probability gap required for top-k rank stability under temperature scaling and quantization) in Section 5.

3. 问题建模

写作策略：第 3 节的符号体系和信道模型直接沿用 ACL 的设定，仅补充新增的排序一致性假设和扩展的威胁模型。

我们沿用 Huang et al. (2026) 的规划时行为信道建模。在每一步 t，Agent 在有限行为集 Bt 上导出一个分布 Pt，并通过 b̂t ← Enc(Pt, rt) 选择行为，其中 rt 是由共享秘密 Ksh 和步骤上下文派生的带密钥伪随机数。验证者通过 m̂ ← Dec({(b̂t, ·)}t∈I) 恢复载荷，其中 I ⊆ {1, …, T} 是观测到的索引集。

我们保留分布保持要求（Huang et al., 2026 的公式 1）：

Pr[b̂t = b] = Pt(b),   ∀ b ∈ Bt, ∀ t.

3.1 扩展的威胁模型

AgentMark-F（Huang et al., 2026）假设验证者能够获得编码时使用的 精确 每步分布 Pt。在实践中，这一假设很脆弱：验证者可能重新查询 Agent 来重建 Pt，但温度缩放、量化、模型更新或 API 端的后处理都可能改变返回的概率值。我们将此形式化为 分布扰动对手：

定义 1（分布扰动） 对手对每一步施加变换 Pt ↦ Pt'，使得概率值发生变化但排序不变：argsort(Pt) = argsort(Pt')。

这比 Huang et al. (2026) 的擦除/截断对手严格更强：步骤擦除会移除整个步骤，而分布扰动则破坏 幸存步骤的内容。AgentMark-F 的差分重组依赖于精确的概率值来构建 bin；在分布扰动下，编码器和解码器构建出不同的 bin，导致同步失效和解码失败（我们在第 5 节中对此进行了实证验证）。

3.2 排序一致性假设

我们引入以下对精确分布要求的松弛：

假设 1（排序一致性） 解码器观测到的分布 Pt' 满足 argsort(Pt') = argsort(Pt)，即行为的相对排序得以保持。

该假设有良好的经验支持：在温度缩放（pi' = pi1/T / Z 是单调的）、轻度微调和量化下，排序是稳定的，这些操作主要缩放幅度而保持相对顺序（我们在第 5 节表 X 中进行了验证）。

目标。 设计编码器 Enc 和解码器 Dec，使得：(1) 分布保持性质如常成立；(2) 解码器仅需 argsort(Pt')——而非精确值——从而在假设 1 下实现正确解码。

4. AsymAgentMark：非对称行为水印

我们提出 AsymAgentMark，即 AgentMark 范式的 非对称 扩展。虽然 AsymAgentMark 和 AgentMark-F 共享分布保持的目标，但 AsymAgentMark 重新设计了编码器和解码器二者：编码器用排序行为上的二叉分割树替换了差分重组，解码器则利用该树的结构性质，仅从排名位置中提取比特，无需概率值。这种联合设计至关重要——AgentMark-F 的差分重组将比特编码到依赖概率的 bin 中，而这些 bin 无法仅从排序信息中恢复，因此非对称解码需要一个根本不同的编码方案。

我们给出了一个具体实例化——AsymAgentMark-T，它通过递归二叉分割在 top-k 排序行为上运作。"-T" 表示基于 top-k 排名的编码：编码器将注意力限制在概率最高的 k 个行为上，在该子集内嵌入比特，对于尾部行为则回退到标准采样。这种 top-k 聚焦既能将嵌入容量集中在信息量最大的动作上，又自然地与常见的推理时截断策略相契合。

核心洞见。 二叉分割树通过交错分割将每个行为映射到唯一的叶子节点。从根到叶子的路径完全由该行为在排序中的排名决定——排名的二进制表示 就是 这条路径。正是这种结构对应关系使非对称解码成为可能：编码器使用概率值来进行分布保持的组选择（通过 BinEnc），而解码器仅从排名中读取同一条路径。

[图 2 规划]：与 ACL 图 2 对称的布局。左侧 Agent 工作流保持一致（沿用 ACL 的 Agent 循环示意）。右侧 AsymAgentMark-T 替换原有的差分重组 + 循环移位模块，改为：按排名排序 → Top-k 选择 → 二叉分割树 → 每层 BinEnc。底部新增一个对比框："解码器需求：AgentMark-F 需要 Pt（精确值）vs. AsymAgentMark-T 需要 σt（仅排序）"，用颜色区分。

图 2 展示了 Agent 工作流中的 AsymAgentMark-T。在每一轮 t：

  1. Agent 在 Bt 上导出一个显式的行为分布 Pt（与 AgentMark-F 相同）。
  2. 编码器按概率降序对 Bt 排序，选择 top-k 行为，并在该子集上通过递归二叉分割嵌入比特（RankEnc）。若采样到的动作落在 top-k 之外，则本步不嵌入任何比特。

4.2 基于排名的分布保持编码

AsymAgentMark-T 用 top-k 排名排序分布上的二叉分割树替换了 AgentMark-F 的差分重组。该构造分为两层：一个二进制编码原语（BinEnc）和一个递归包装器（RankEnc）。

二进制编码原语

在树的每一层，编码器面临两组行为之间的二元选择。BinEnc 尝试将一个消息比特嵌入此选择，同时 精确保持边缘分布。当低质量组被选中时，它成功（嵌入 1 比特）；当高质量组被选中时，它推迟（嵌入 0 比特）——此时同一消息比特将在下一层重试。

给定组质量 Shi ≥ Slo（且 S = Shi + Slo）、消息比特 m 和伪随机数 r ← G：

rm = (r · S + ½ S · m) mod S

编码器在 rm < Shi 时选择高质量组（嵌入 0 比特），否则选择低质量组（嵌入 1 比特）。分布保持性来自 r 的均匀分布（证明见附录 B）。

带 Top-k 选择的递归编码

[图 3 规划]：5-action 示例，与 ACL 的差分重组示例并排对比。左列标 "AgentMark-F: 差分重组 → Bins → 循环移位"，右列标 "AsymAgentMark-T: Top-k → 排序 → 二叉分割树"。底部高亮：同一个动作被选中后，AgentMark-F 解码需要精确概率重建 bin，AsymAgentMark-T 解码只需排名位置。

算法 1：AsymAgentMark-T 编码（单步）

输入: P_t 定义在 B_t 上, 上下文 (t, h_t), 共享秘密 K_sh,
      载荷 M, 指针 ℓ, top-k 参数 k
输出: 选中的行为 b̂_t, 嵌入的比特 s_t, 更新后的 ℓ

1:  K_t ← H(K_sh ∥ t ∥ h_t);  G ← DRBG(K_t)
2:  σ ← argsort(P_t, 降序)
3:  S_top ← Σ_{i=1}^{k} P_t(σ(i))                ▷ top-k 概率质量
4:  if Uniform(0,1) ≥ S_top:                       ▷ 落入尾部（与 G 无关）
5:      b̂_t ← 从尾部 {σ(k+1), ...} 采样; return b̂_t, ∅, ℓ
6:  D ← {(σ(i), P_t(σ(i))/S_top) : i = 1..k}     ▷ top-k 归一化分布
7:  sync ← ⌈log₂ k⌉
8:  while |D| > 1 且 ℓ < |M|:
9:      D_even ← {D[i] : i 为偶数};  D_odd ← {D[i] : i 为奇数}
10:     (group, b) ← BinEnc(M[ℓ], (Σ D_even, Σ D_odd), G.next())
11:     ℓ ← ℓ + b;  sync ← sync − 1;  D ← D_group
12: for i = 1 to sync: G.next()                    ▷ PRG 同步
13: b̂_t ← D[0];  s_t ← M[ℓ_old : ℓ]
14: return b̂_t, s_t, ℓ

Top-k 选择（第 3–6 行）。 AsymAgentMark-T 并非在整个行为集上编码，而是限制在概率最高的 k 个行为上。这一设计基于三点考量：(1) 排名稳定性——top-k 排名对概率扰动最为鲁棒，因为排名靠前的行为之间的概率差距通常大于尾部行为之间的差距；(2) 推理对齐——许多 Agent 部署已经应用了 top-k 截断，因此这是自然的契合；(3) 嵌入集中——top-k 行为承载了大部分概率质量，因此限制在该子集上牺牲的容量很小，同时提升了鲁棒性。当 k = |Bt| 时，AsymAgentMark-T 退化为全分布编码。

交错分割。 在每一层，我们将排序后的分布划分为偶数索引和奇数索引的元素。由于分布按降序排列，偶数索引组（包含排名 0, 2, 4, ...）的总质量始终 ≥ 奇数索引组（排名 1, 3, 5, ...）。这种交错方式保证了近似均衡的组质量，最大化每层的嵌入机会。若采用简单的前半/后半分割，会产生一个占主导的高质量组，导致 BinEnc 几乎总是选择它，嵌入率接近于零。

PRG 同步（rt_sync）。 DRBG 每步恰好推进 ⌈log₂ k⌉ 次调用，无论是否提前终止（第 12 行）。这一固定预算不变性至关重要：没有它，解码器无法确定消耗了多少 DRBG 值，导致所有后续步骤的流去同步。这一机制还使解码器能够在不知道消息长度的情况下运行——这是 AgentMark-F 的变长循环移位编码所不具备的特性。

4.3 弱非对称解码

AsymAgentMark 的核心贡献是一个 联合设计的编码器-解码器对，其中编码器的二叉分割树结构直接使解码器能够仅需更少信息即可工作。编码器的树结构设计并非偶然——它是使非对称解码成为可能的结构性前提。

关键观察。 二叉分割树将每个行为映射到一个唯一的叶子节点。从根到行为叶子节点的路径完全由该行为在 top-k 集合中的排名决定：在每一层，属于高质量组还是低质量组对应于当前索引是偶数还是奇数——即该层排名的奇偶性。因此，排名的二进制表示 就是 编码路径。这一性质是交错二叉分割独有的；AgentMark-F 的差分 bin 不支持这种基于排名的路径恢复。

算法 2：AsymAgentMark-T 解码（单步）

输入: b̂_t, 排序 σ_t, 上下文 (t, h_t), 共享秘密 K_sh,
      top-k 参数 k
输出: 提取的比特串 s_t

1:  K_t ← H(K_sh ∥ t ∥ h_t);  G ← DRBG(K_t)
2:  rank ← b̂_t 在 σ_t[1..k] 中的位置（从 0 开始索引）
3:  if b̂_t ∉ σ_t 的 top-k: return ∅           ▷ 尾部动作，无比特
4:  sync ← ⌈log₂ k⌉
5:  R ← [G.next() for _ in range(sync)]
6:  s_t ← "";  level ← 0
7:  while rank ≠ 0:
8:      if rank mod 2 = 1:                      ▷ 奇数索引组 → 嵌入比特
9:          s_t ← s_t ∥ ('1' if R[level] < 0.5 else '0')
10:     rank ← ⌊rank / 2⌋;  level ← level + 1
11: return s_t

注意非对称性：算法 1（编码器）访问完整分布 Pt 来计算 BinEnc 的组质量（第 10 行）。算法 2（解码器）仅访问排序 σt（第 2 行）——概率值从未出现。解码器只需要知道被选中行为在 top-k 集合中的位置（排名）。

定理 1（弱非对称性）。 设 Pt 和 Pt' 为 Bt 上的分布，满足 argsortk(Pt) = argsortk(Pt')（即 top-k 排名顺序保持不变）。对于任意行为 b̂t 和 DRBG 状态 G：

Decode(b̂t, sort(Pt), G) = Decode(b̂t, sort(Pt'), G)

证明。 Decode 仅通过 top-k 排序 σt = argsortk(Pt) 访问 Pt。由于该排序得以保持，b̂t 在 top-k 集合中的排名在两个分布下完全相同。DRBG 序列仅依赖于 (Ksh, t, ht)，与概率值无关。□

4.4 与 AgentMark-F 的对比

AgentMark-F 和 AsymAgentMark-T 都是 AgentMark 范式的分布保持实例化。它们在分解策略、解码器信息需求和由此产生的鲁棒性特征上有所不同：

AgentMark-F (Huang et al., 2026)AsymAgentMark-T (本文)
分解方式差分重组 → 均匀 binsTop-k 排名排序的二叉分割树
编码器输入Pt（精确概率）Pt（精确概率）
解码器输入Pt（精确概率）σt（仅 top-k 排名顺序）
每步比特数可变，取决于 bin 大小≤ ⌈log₂ k⌉
PRG 同步固定 2 次调用/步（隐式）显式固定预算 ⌈log₂ k⌉
鲁棒性擦除/截断（通过 RLNC）擦除 + 分布扰动
脆弱性概率扰动破坏 bin 同步排名交换攻击（top-k 内）破坏排名同步

何时选择何种方案。 AgentMark-F 在受控环境中（编码者和验证者共享相同的 API 和配置）可实现更高的嵌入率，此时解码时可以获得精确的 Pt。AsymAgentMark-T 适用于验证者无法保证精确 Pt 的场景——这是开放世界部署中的常见情况，其中 Agent 可能被重新服务、微调或通过不同的 API 配置访问。top-k 限制通过聚焦于排名最稳定的行为进一步提升了鲁棒性。

与 RLNC 的兼容性。 AsymAgentMark-T 与 AgentMark-F 的 RLNC 纠删编码层完全兼容。Encode 产生的每步嵌入比特 st 可以像 AgentMark-F 的循环移位输出一样作为 RLNC 编码包使用（Huang et al., 2026 第 4.3 节）。

4.5 安全属性

AsymAgentMark-T 通过不同的构造实现了与 AgentMark-F 相同的安全保障：

分布保持性。 在均匀消息比特条件下，BinEnc 在 top-k 集合上产生的边缘分布精确匹配 Pt（命题 1；证明见附录 B）。结合概率比例尾部回退（算法 1，第 4–5 行），整体边缘分布在所有行为上匹配 Pt。AsymAgentMark-T 和 AgentMark-F 都满足相同的分布保持性质（公式 1），但通过完全不同的机制实现：AgentMark-F 通过对概率依赖的均匀 bin 进行差分重组，而 AsymAgentMark-T 通过在排序二叉分割树上进行递归 BinEnc。

不可检测性。 在 HMAC-SHA512 的 PRF 假设下，DRBG 输出在计算上与均匀随机比特不可区分，使得带水印的行为序列与无水印的采样不可区分。这直接来自 Meteor DRBG 的安全论证 [Kaptchuk et al., 2021] 和 FDPSS 框架 [Liao et al., 2025]。

新增：扰动鲁棒性。 根据定理 1，AsymAgentMark-T 额外保证了在任何保持 top-k 排名顺序的分布扰动下都能正确解码——这是 AgentMark-F 不具备的性质。top-k 限制增强了这一保证：最主导行为之间的概率差距通常更大，使其排名对扰动更具抵抗力。我们在第 5 节中量化了这一边界（即在温度缩放和量化下保持 top-k 排名稳定所需的最小概率差距）。
